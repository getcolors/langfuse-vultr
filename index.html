langfuse-vultr

Desired state for self-hosted Langfuse v4 on six Vultr machines in one VPC, converged by the langfuse Package Skill: a Neon storage tier, Redis, three ClickHouse replicas with Keeper, and the application host behind Cloudflare.

Desired state only. This repository is a colors.yml, an installed launcher, an .envrc and a devenv.nix. Everything else is generated under .colors/ or secret in .envrc.private.

Use

./green build
./green create --dry-run
./green create
./green describe
./green rehearse

Recovery

Postgres dumps every six hours, ClickHouse backups nightly, media archived additively — all with completion markers in the backup bucket. ./green rehearse restores both stores, boots the pinned image against them, reads through the API, drills a replica loss and a Redis restart, and writes .colors-recovery-verified.

Three secrets are operator-held. ENCRYPTION_KEY, SALT and the initial user's password live in .envrc.private and must also live somewhere that is not one of these machines: a Postgres backup is readable only with the first two.
